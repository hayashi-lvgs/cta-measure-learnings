# CTA-4226 — EF 性別に「回答しない」を追加（SP/PC・AB無）

## 基本情報

| 項目 | 内容 |
|---|---|
| 施策ID | CTA-4226 |
| 対象箇所 / 要素 | EF / 性別 |
| 対象デバイス | SP / PC |
| KPI / サブKPI | EF完了率（一覧シート）／ 詳細シート上は主KPI=EF突破率・サブKPI=CVR |
| 検証期間 | 2025/04/04〜2025/04/11 |
| 改善率 | 100% |
| 判定結果 | **引き分け** |
| 寄せ | 寄せない |

## 施策概要

- **施策背景**: 昨今のポリコレの潮流に合わせ、性別を限定的にしないようにする必要がある
- **課題**: 「性別」を回答する際、「男性」もしくは「女性」しか選択できない
- **ターゲット**: 性別回答に躊躇する就活生
- **仮説**: ポリコレ対応のため特になし
- **施策内容**: 性別の選択肢に「回答しない」を追加（前後比較・ABなし）

## 結果要因

### 検証結果（要点）

- EF突破率（mobile）: cpc 100.00%→100.00%（改善率100%）／ organic 99.14%→100.00%（改善率101%）
- EF完了率（mobile）: cpc 25.66%→18.31%（改善率71%）／ organic 29.03%→24.39%（改善率84%）
- 有意差: すべてにおいて有意差なし

### 考察（なぜその結果になったか）

- EF完了率・EF突破率が改善しなかった要因
  - 性別の「回答なし」の追加は、就活生のEF入力にさほど影響を与えていない可能性がある
  - LGBTQなどのセクシャルマイノリティは人口に対して少数派であり、CTへのそもそもの流入数がさほど多くないため、効果がなかった可能性がある
- EF完了率が低下している要因
  - 例年3月のEF完了率は17%（cpc）・10%（organic）であり、それらよりも施策前後のレートは高い
  - 施策前後の実績値は上振れ・下振れの範囲内であり、施策前のレートが上振れていた可能性が高い

### 学び / 気づき

- 性別の「回答なし」の追加は、ユーザーのEF突破率および完了率に直接的な影響を与えない
