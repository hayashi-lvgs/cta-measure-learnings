## 施策概要

- **施策名（シート）**: 記事詳細ページ_SP/PC_適職診断EF導入によるCVR改善_新バナー_ABC
- **施策背景**（これまでの適職診断EF関連CRO施策で判明していたこと）:
  - 「目次直上にCTAボタン」vs「目次直上に適職診断バナー」だと後者は負けた
  - サムネイル削除時のCVRは「サムネ削除の目次直上CTA」＞「サムネ削除の目次直上適職診断バナー」＞「サムネありの通常CTA」
  - サムネイル削除して目次直下に適職診断バナーを挿入した場合は「目次直下の適職診断バナー」＞「目次直下の通常CTA」＞「目次直下に何もなし」
  - 現時点では「サムネ削除∧目次直下に適職診断バナー」が最もCVR改善だが、HTほどレートは改善していない。理由として想定される2要因: 適職診断EFがユーザーに刺さっていない可能性／適職診断バナーが「広告感のあるもの」と認識されスキップされている可能性
- **課題**: 適職診断EFがユーザーに刺さっていない可能性／適職診断バナーが「広告感のあるもの」と認識されスキップされている可能性
- **ターゲット**: SEO記事を見て流入したユーザー
- **仮説**: 広告感のないバナーに変更することで、適職診断バナーのMCVRが改善される
- **施策内容**: サムネイル削除のうえ適職診断EFバナーを目次直下に挿入し、新パターン vs 旧パターンを比較（カテゴリごとに数値計測）。A（Original）／B（広告型バナー＝旧型）／C（ボタン型バナー＝新型）のABC、AB / optimize

## 結果要因

### 検証結果（要点）
- 改善率（SP）: Original vs 旧型バナー = MCVR 103.4% / EF完了率 134.3% / CVR 138.9%、Original vs 新型バナー = MCVR 88.5% / EF完了率 143.9% / CVR 127.4%、旧型 vs 新型 = MCVR 116.8% / EF完了率 93.3% / CVR 109.0%
- 改善率（PC）: Original vs 旧型バナー = MCVR 99.3% / EF完了率 68.8% / CVR 68.3%、Original vs 新型バナー = MCVR 104.0% / EF完了率 107.3% / CVR 111.6%、旧型 vs 新型 = MCVR 95.4% / EF完了率 64.1% / CVR 61.2%
- 検定: カイ二乗検定・ベイズ統計確率ともに、いずれも有意差なし
- 一覧シート上の最終値: 改善率 88.50%（SPのOriginal vs 新型バナーMCVR）／ 判定 **負け** ／ 寄せ 寄せない ／ 検証期間 2026/01/13〜2026/02/10
  - ※スライスのNAでは暫定対応として「SP＝旧型バナー寄せ／PC＝新型バナー寄せ」との記載あり（一覧シート最終値の「寄せない」とは差異）

### 考察（なぜその結果になったか）
- 結果概要:
  - SP: 目次直下に適職診断バナーを入れるとCVRは改善、特に旧型バナーで改善率が大きい
  - PC: 目次直下に新型バナーを入れた場合のみCVR改善、旧型バナーではCVRが悪化
  - カテゴリ別では勝ちパターンが異なる（企業研究・業界研究は新型でCVR2倍以上、自己PR・連絡は旧型でCVR3倍近く、身だしなみ・内定はOriginalが最良）
- SPについて:
  - 旧型バナーの方がMCVRが高かった → ユーザーはそもそも旧型バナーに広告感を感じていない可能性／新型バナーはクリエイティブが目立っていなかった可能性（視覚的に柔らかく印象に残らなかった可能性）
  - 新型バナーの方がEF完了率が高かった → コピーに「向いてる仕事がわかる」という便益が明確に記載され、違和感なく登録完了まで移れた可能性
- PCについて:
  - 新型バナーの方がMCVR・EF完了率が高かった → 便益明示によるEF改善に加え、SPより画面に対する占有率が新型で大きく目立ったためMCVRが改善したと考えられる
- 記事カテゴリごと: カテゴリ（≒就活フェーズ）によって刺さるコンテンツ（≒ニーズ）が異なるため反応に違いが出たと考えられる

### 学び / 気づき
- デバイスごとのユーザー反応傾向は異なるため、カテゴリごとに最適化した緻密なプランニングが必要

### ネクストアクション（NA）
- 暫定対応: SPは旧型バナー寄せ、PCは新型バナー寄せ
- CVR改善観点: デバイスごとに異なるクリエイティブで最適化／PC版は画面に対する占有率が大きいクリエイティブを意識／カテゴリごとに適したコンテンツを制作（「適職診断EF」のようなCEPコンテンツは全カテゴリ横断より各カテゴリ最適化の方がCVR改善の総量が大きくなりそう）
- 適職診断バナー改善観点: 「向いてる仕事がわかる」という便益を入れる
- （その他備考）保守運用観点からインパクトの大きいデバイス／カテゴリの勝ちパターンに寄せる。デバイス×カテゴリ最適化は40パターン制作が必要なため、特異なものでない限りカテゴリ横断で寄せはしない。全く異なるクリエイティブでなければデバイスごとにコミュニケーションを変えるのは問題なさそう
