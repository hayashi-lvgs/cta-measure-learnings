# CTA-4183 — EF 未使用項目の削除（SP/PC・AB無）

## 基本情報

| 項目 | 内容 |
|---|---|
| 施策ID | CTA-4183 |
| 対象箇所 / 要素 | EF / 性別（一覧シート表記）※詳細シートでは「都道府県」「就活終了希望時期」の項目削除 |
| 対象デバイス | SP / PC |
| KPI / サブKPI | EF完了率 / CVR |
| 検証期間 | 2025/04/04〜2025/04/11 |
| 改善率 | 100% |
| 判定結果 | **引き分け** |
| 寄せ | 寄せない |

## 施策概要

- **施策背景**:
  - EF入力項目で、CT事業部側でカウンセリング予約やマーケ分析の際に使用していない項目がある（都道府県・就活終了希望時期）
  - 上記を削除することで、EF入力をスムーズに行うことができる可能性がある
- **課題**: 不要な項目が残っているために、EF完了に必要な入力数が多くなっている
- **ターゲット**: EFを素早く入力したい就活生
- **仮説**: 入力項目を減らすことで、EF完了率が向上する
- **施策内容**: 使用していない入力項目（都道府県・就活終了希望時期）を削除（前後比較・ABなし）

## 結果要因

### 検証結果（要点）

- EF完了率（mobile）: cpc 25.66%→18.31%（改善率71%）／ organic 29.03%→24.39%（改善率84%）
- 有意差: 有意差なし

### 考察（なぜその結果になったか）

- EF完了率・EF突破率が改善しなかった要因
  - 「都道府県」や「就活希望終了時期」の項目削除は、就活生のEF入力にさほど影響を与えていない可能性がある
- EF完了率が低下している要因
  - 例年3月のEF完了率は17%（cpc）・10%（organic）であり、それらよりも施策前後のレートは高い
  - 施策前後の実績値は上振れ・下振れの範囲内であり、施策前のレートが上振れていた可能性が高い

### 学び / 気づき

- （回答の手間が少ない）設問の「項目削除」は、ユーザーの完了率に直接的な影響を与えない可能性がある
