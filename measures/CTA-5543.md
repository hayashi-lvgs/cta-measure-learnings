# CTA-5543 — EF 生年月日入力欄の改修（SP/PC・AB無）

## 基本情報

| 項目 | 内容 |
|---|---|
| 施策ID | CTA-5543 |
| 対象箇所 / 要素 | EF / 生年月日 |
| 対象デバイス | SP / PC |
| KPI / サブKPI | EF完了率（一覧シート）／ 詳細シート上は主KPI=EF突破率・サブKPI=EF完了率 |
| 検証期間 | 2025/03/17〜2025/04/02 |
| 改善率 | 150% |
| 判定結果 | **勝ち** |
| 寄せ | 寄せ済み |

## 施策概要

- **施策背景**:
  - EFの入力項目のうち、生年月日の項目が最も突破率が低い
  - EFの入力項目で、最も突破率の改善率（インパクト）が大きいとみられる
- **課題**: 生年月日入力欄がパッと見では何を入力すればよいかわからない
  - プレースホルダーの生年月日が24卒の年になっている
  - プレースホルダーの生年月日に「/」などがなく、8桁の数字にしか見えず生年月日として認識されにくい
- **ターゲット**: 設問内容を見ずに入力欄だけを見て入力している就活生
- **仮説**:
  - 表示されている数字が何を示しているかわからない
  - 表示されている数字が生年月日として認識されていない
- **施策内容**: 生年月日入力欄のプレースホルダー等を改修し、何を入力すべきかを直感的にわかるようにした（前後比較・ABなし）

## 結果要因

### 検証結果（要点）

- EF完了率（サブKPI）: cpc 18.88%→29.58%（改善率157%）／ organic 20.11%→34.15%（改善率150%）
- EF突破率（主KPI）: cpc 90.24%→88.99%（改善率99%）／ organic 91.85%→95.52%（改善率104%）
- 有意差: EF完了率のみ有意差あり

### 考察（なぜその結果になったか）

- EF突破率が改善しなかった要因
  - サンプルサイズに依るブレの可能性。EF突破率は日次での変動が激しく、考察記載の前日（2025/04/02）では全経路が改善傾向にあった
- EF完了率が改善した要因
  - 生年月日入力欄が、設問を見なくても何を記入すればよいかが直感的にわかりやすくなったため、これまで離脱していた顕在層をこぼすことなく展開させることができた
