# CTA-13038 — 記事詳細PC サイドバナー型CTA導入によるCVR改善

## 基本情報

| 項目 | 内容 |
|---|---|
| 施策ID | CTA-13038 |
| 対象箇所 / 要素 | 記事詳細 / CTAボタン（サイドバナー型CTA） |
| 対象デバイス | PC |
| KPI / サブKPI | CVR / MCVR |
| 検証期間 | 2026/05/13〜2026/05/27 |
| 改善率 | 223% |
| 判定結果 | **勝ち** |
| 寄せ | 寄せ済み |

## 施策概要

- **施策背景**:
  - PCはSP版と比べてMCVRが低い
  - PC画面での登録導線は、ヘッダー追従CTA / 目次直上CTA（MCVR高） / h2直下CTA（MCVR高） / フッター追従CTAがある
  - 「h2直下CTA」はMCVRが高いが、大見出し（h2）内のテキスト量が多いため常に画面に表示されてはいない
  - ページに新規で登録導線を設置することで、MCVRおよびCVRを改善できる可能性がある
- **課題**: PCはSP版と比べてMCVRが低い
- **ターゲット**: 記事詳細ページを見に来ている就活生
- **仮説**: PCページに新規で登録導線を設置する（=CEPを増やす）ことで、MCVRおよびCVRを改善できるのではないか
- **施策内容**: PCの記事詳細ページにサイドバナー型CTAを新規導入し、Original（A）と比較するABテスト

## 結果要因

### 検証結果（要点）
- 改善率（一覧シート最終値）: CVR 223%（勝ち）
- スライス記載の実績値: MCVR 152%改善 / EF完了率 147%改善 / CVR 223%改善
- パターン別（参考データ）: Original SS 8,651・CV 5・CVR 0.06%、サイドバナーあり SS 8,518・CV 11・CVR 0.13%
- 検定: カイ二乗検定 / ベイズ統計確率で検定したが、いずれも有意な差はなし（CVR カイ二乗0.126 / ベイズ0.932）

### 考察（なぜその結果になったか）
- サイドバナー設置によりCVRが+223%と大幅改善。記事閲覧中に常時CTAが表示されることで、情報収集フェーズのユーザーを逃さず刈り取れた
- EF完了率も+147%改善しており、バナー経由ユーザーは離脱が少なく質が高いと考えられ、顕在層をフィルタリングできているとみられる
- 記事見出し内CTAのクリック数はほぼ横ばい（18→19）でカニバリしておらず、全体CVが5件→11件に増えていることから、サイドバナーと記事CTAが補完関係として機能している

### 学び / 気づき
- 「就活の進め方がわからない」訴求のCTRが0.093%と、他訴求（0.000%・0.013%）を大きく上回り、ユーザーの顕在的な悩みに刺さる文言の重要性を再確認（CVした卒年は半々で、特定の卒年に刺さったわけではない）

### ネクストアクション（NA）
- 時期ごと・記事カテゴリごとに「就活の進め方がわからない」訴求文言を変更し、さらなるCTR・CVR改善を狙う
